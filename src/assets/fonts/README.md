# F1 STORIES typography

Unmodified WOFF2 files copied from `f1StoriesPage/assets/fonts/` from the local F1 Stories checkout at revision `dd1671e07eddc4ee06ec3ef667b8b8f00c500206`.
Source: https://github.com/georgiosbalatzis/f1StoriesPage/tree/dd1671e07eddc4ee06ec3ef667b8b8f00c500206/assets/fonts

IBM Plex Sans variable subsets: Latin, Latin-ext, Greek and arrows, weights 400–600. Barlow Condensed: Latin, weight 700, for product/parent wordmarks only. IBM Plex Sans is the Greek fallback for brand text.

Both families use SIL Open Font License 1.1. The upstream license files are included alongside the font files. `src/styles/fonts.css` adapts `styles/home-fonts.css` URLs for Vite and retains the metric-matched local fallback declarations from `styles/editorial.css`. No remote font requests are needed.
